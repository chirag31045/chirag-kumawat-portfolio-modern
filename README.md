# Chirag Kumawat — Modern Developer Portfolio

React + Vite portfolio customized from Chirag Kumawat's CV.

## Highlights
- Modern responsive UI with light/dark mode
- Sticky responsive header + mobile menu
- Animated hover cards for skills and projects
- Swami Vivekanand Samiti GitHub link
- IPL Team Management GitHub link
- Real Estate CRM marked as a live company project
- WhatsApp, phone, email, LinkedIn and GitHub contact links
- Resume PDF download from `/public/Chirag_Kumawat_ATS_Resume.pdf`
- Education cards with institution/board logo badges
- Responsive footer
